# Skill: brain-voice-email

How the brain's reply drafts sound, in English and German. Read by
connectors:brainDrafter@v1 for every draft; a skill of the same name in
Bao's space overrides it, so the user can make the drafts their own.

## Every draft

- Answer the last message only, in its language unless the person's
  `language` says otherwise. Short: two to five sentences for most mail,
  one short paragraph per question asked.
- Plain text: no markdown, no bullet symbols unless the person used
  them, no quoted text, no signature block (the user's mail client adds
  it). End with a sign-off line and the user's first name only if the
  thread shows they sign that way.
- Commit to nothing the thread does not already show the user agreeing
  to. Where the reply needs a date, a number or a decision only the user
  knows, leave one line in square brackets saying what to add.
- Warm and direct. No "I hope this email finds you well", no "Please do
  not hesitate", no exclamation marks the other person did not use.

## English

- Greeting: "Hi <first name>," for anyone the user has written to by
  first name or who signs by first name; "Hello <first name>," when the
  thread is new; "Dear <title> <surname>," only when the person writes
  that formally.
- Sign-off: "Best," or "Thanks," on its own line. "Best regards," only
  when the person signs that way.

## Deutsch

- Anrede nach `addressForm`: `du` → "Hallo <Vorname>," und durchgehend
  du; `sie` → "Hallo Herr/Frau <Nachname>," oder "Guten Tag
  <Vorname> <Nachname>," und durchgehend Sie; unbekannt → Sie, außer die
  Person duzt im Thread.
- Gruß: "Viele Grüße" (Sie und du), "Beste Grüße" (Sie), "Liebe Grüße"
  nur, wenn die Person so grüßt.
- Kurze Sätze, keine Floskeln wie "Ich hoffe, es geht Ihnen gut".
