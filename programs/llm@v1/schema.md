### chat(messages, system?, tier?, tools?) [getter]
One model call. `messages`: `[{"role": "user"|"assistant", "parts": [Part]}]` — Part is `{"type": "text", "text"}` for plain turns; `tool_call`/`tool_result`/`thinking` parts round-trip loop traffic. `system`: system prompt string. `tier`: `"codegen"` (default, the strong model) or `"classify"` (fast/cheap — one-off judgments). `tools`: `[{name, description, input_schema?}]`, empty for plain completions. Returns the neutral Reply `{parts, stop: "done"|"tool"|"length", usage: {in, out}}`. A ≥400 provider status raises `LlmError(status, body_excerpt)`.
